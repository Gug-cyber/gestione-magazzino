# 🧪 Test Automazione

Questo file è stato aggiunto per verificare il corretto funzionamento dei workflow di automazione del repository (CI/CD, checks, ecc.).

## Scopo

Questa nota di test permette di:
- Verificare che le GitHub Actions si attivino correttamente sulle pull request
- Confermare che i controlli automatici (linting, test, security scan) funzionino
- Validare il processo di review e merge automatizzato

## Nota

Questa è una modifica di test che non impatta la funzionalità esistente del software.
